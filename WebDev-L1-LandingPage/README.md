# SaaSify - Product Landing Page

A modern, responsive landing page built as part of the Web Development & Designing track for the Oasis Infobyte SIP Internship.

## Project Details
- **Track**: Web Development & Designing
- **Level**: Level 1
- **Task**: Task 1 (Landing Page)
- **Tech Stack**: HTML5, CSS3

## Features Implemented
- Sticky navigation bar with anchor links
- Hero section with title, value proposition, and CTA buttons
- Feature highlight cards built with CSS Grid
- About section and Customer Reviews section
- Multi-column footer layout with quick links
- Fully responsive design for desktop, tablet, and mobile viewports
