# Personal Portfolio Website

A personal portfolio web application built as part of the Web Development & Designing track for the Oasis Infobyte SIP Internship.

## Project Details
- **Track**: Web Development & Designing
- **Level**: Level 1
- **Task**: Task 2 (Personal Portfolio)
- **Tech Stack**: HTML5, CSS3

## Features Implemented
- Sticky navigation bar with anchor scroll links
- Profile hero section with title and introduction
- About Me summary highlighting background
- Skills section with clean badge grid
- Projects section highlighting completed projects
- Contact section with email and social profile links
- Responsive layout across desktop and mobile screens
