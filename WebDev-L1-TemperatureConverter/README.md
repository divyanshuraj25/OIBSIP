# Temperature Converter Website

An interactive temperature conversion web utility built as part of the Web Development & Designing track for the Oasis Infobyte SIP Internship.

## Project Details
- **Track**: Web Development & Designing
- **Level**: Level 1
- **Task**: Task 3 (Temperature Converter Website)
- **Tech Stack**: HTML5, CSS3, Vanilla JavaScript

## Features Implemented
- Dynamic conversion across Celsius, Fahrenheit, and Kelvin units
- Strict input validation rejecting empty and non-numeric inputs
- Edge-case validation enforcing absolute-zero limits (-273.15°C / 0 K)
- Simultaneous calculation showing all output units together
- Modern, clean, and mobile-friendly centered UI layout
